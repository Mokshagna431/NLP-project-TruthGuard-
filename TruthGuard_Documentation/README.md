## 5. Viva Voce Defense Quick Reference Guide

When defending TruthGuard in an academic evaluation, viva voce, or capstone review:

1. **Open with the 2-Minute Elevator Pitch (Explanation Manual Section 16.7):**  
   Highlight that LLMs optimize probability rather than truth, and that TruthGuard solves this by acting as an independent, deterministic proof engine that verifies facts downstream of text generation.
2. **Emphasize the 3 Core Research Innovations:**
   - **Symmetrical Universal AI Investigation:** Unlike existing fact-checking systems that only re-investigate uncertain (NEI) claims, TruthGuard actively investigates all three verdicts, hunting for counter-evidence on Supported claims and checking historical nuance on Contradicted claims.
   - **Weakest-Link Non-Compensatory Reliability:** Linear averaging allows fatal lies to score 90% (High Trust) if surrounded by true facts. TruthGuard bounds reliability by the maximum contradiction probability: $R(A) = \min(\text{mean}(\rho), 1 - \max(P_C))$.
   - **Verify-Then-Accept Grounded Correction:** M5 resolves the duplicate paragraph correction bug using semantic deduplication and validates every candidate edit against external evidence before acceptance (3.48% False Correction Rate).
3. **Present the Empirical Data from Slide 15:**  
   Cite the real numbers from TruthGuard-350: 82.86% overall accuracy, 93.78% Contradiction F1, and 100% retrieval relevance rate.
4. **Refer Evaluators to Chapter 16 for Technical Deep Dives:**  
   If examiners ask about mathematical calibration, refer to Chapter 7 (Temperature Scaling $T=1.35$) and Chapter 9. If asked about edge cases, refer to the 9 real case studies in Chapter 15.
